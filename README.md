## 👨‍💻 Sobre mí

Soy desarrollador de software interesado en crear aplicaciones modernas, automatizar procesos e integrar tecnologías para desarrollar soluciones útiles para personas y empresas.

Me gusta participar en distintas etapas del desarrollo: desde la interfaz de usuario y la lógica del negocio hasta las API, las bases de datos y la infraestructura necesaria para desplegar aplicaciones.

```text
┌──────────────────────────────────────────────┐
│  MENDOZA SVATORE                              │
├──────────────────────────────────────────────┤
│  Enfoque     Desarrollo de software           │
│  Especialidad Aplicaciones web y backend      │
│  Intereses   IA, automatización y cloud       │
│  Objetivo    Software escalable y mantenible  │
└──────────────────────────────────────────────┘
```

- 🔭 **Desarrollo:** Aplicaciones web y sistemas de gestión empresarial.
- 🌱 **Aprendizaje:** Next.js, TypeScript y arquitectura de software.
- 🤖 **Exploración:** Inteligencia artificial e integración de servicios.
- ☁️ **Infraestructura:** Docker, AWS, Linux y despliegues.
- 🧩 **Intereses:** API, bases de datos, automatización y sistemas distribuidos.
- 🎯 **Enfoque:** Código mantenible, soluciones prácticas y aprendizaje continuo.
