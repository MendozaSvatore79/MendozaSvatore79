## 👨‍💻 Sobre mí

Soy desarrollador de software y me apasiona crear aplicaciones modernas, automatizar procesos e integrar tecnologías para resolver problemas del mundo real.

Me gusta trabajar en las distintas capas del desarrollo, desde el diseño de interfaces y la creación de API hasta la administración de bases de datos, contenedores e infraestructura en la nube.

- 🔭 **Actualmente desarrollando:** Aplicaciones web, sistemas de gestión empresarial y soluciones de automatización.
- 🌱 **Actualmente aprendiendo:** Next.js, TypeScript, sistemas distribuidos y arquitectura en la nube.
- 🤖 **Intereses:** Inteligencia artificial, integración de API y automatización inteligente.
- ☁️ **Infraestructura:** Docker, AWS, Linux y procesos de despliegue.
- 🎯 **Objetivo:** Crear software confiable, escalable y fácil de mantener.
- 💡 **Filosofía:** Aprender constantemente, construir con disciplina y mejorar cada día.
